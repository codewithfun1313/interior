# Embroshyal 🌟

A modern React & Vite web application for luxury interior design, modular kitchens, and signature collections.

## 🚀 Getting Started

Follow these steps to set up and run the project locally:

### 1. Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (version 18 or above recommended) installed on your system.

### 2. Installation
Clone the repository and install the dependencies:
```bash
git clone <your-repository-url>
cd embroshyal
npm install
```

### 3. Running the Development Server
Start the local Vite dev server:
```bash
npm run dev
```

### 4. Build for Production
To build the application for production deployment:
```bash
npm run build
```

---
*Note: `node_modules/` and `dist/` are automatically excluded via `.gitignore`.*
